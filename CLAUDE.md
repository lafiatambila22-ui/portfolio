# Portfolio

Personal portfolio website.

## Stack

- Single HTML file (`index.html`)
- Vanilla CSS in a `<style>` tag inside the same file
- No JavaScript
- No frameworks, no build tools, no dependencies, no npm

## Conventions

- Use semantic HTML elements (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`, `<article>`, etc.)
- Keep all CSS inside the `<style>` tag in `<head>` — no external stylesheets, no inline styles
- Do not add any `<script>` tags or JavaScript of any kind
- Do not introduce npm packages, CDN links, or any external dependencies

## Editing

- All changes go in `index.html`
- No new files unless explicitly requested
